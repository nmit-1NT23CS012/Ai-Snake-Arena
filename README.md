# AI Snake Arena

A Snake game built with Python and Pygame. Control the player snake, collect food, and compete with AI-controlled snakes in an arena.

## Features

- Play with the arrow keys or steer toward the mouse cursor.
- Hold **Shift** to sprint.
- Pause and resume the game.
- Compete against five AI snakes and see scores on the leaderboard.
- Restart after a game over.

## Requirements

- Python 3
- Pygame

## Run the game

1. Clone the repository and open its directory:

   ```bash
   git clone https://github.com/nmit-1NT23CS012/Ai-Snake-Arena.git
   cd Ai-Snake-Arena
   ```

2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Start the game:

   ```bash
   python main.py
   ```

## Controls

- **Arrow keys**: steer the snake when using keyboard control.
- **Mouse Control**: choose mouse steering from the start screen; the snake follows the cursor.
- **Shift**: sprint.
- **Pause button**: pause or resume.
- **Space**: restart after game over.
- **Esc**: quit.
